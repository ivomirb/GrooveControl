v1.1.0
* New feature: Support for a gamepad. You can jog with the analog sticks and assign actions to buttons
* New feature: Large monitor support. You can view two panels at the same time (e.g. the 3d view and the G-code editor)
* Improvement: More acurrate job duration estimate
* Improvement: Updated alarm and error messages for FluidNC
* Safety fix: Stop the CNC machine when the app is closed or when the port is disconnected
* Security fix: Prevent external websites from accessing the app
* Security fix: OpenBuilds CAM integraton is removed, as the website doesn't exist anymore and is a security risk
* Note: The autostart and tray icon are disabled by default as they were mostly needed for OpenBuilds CAM. They can be turned on from the settings

v1.0.3
* Add optional second pass to the probing sequence to improve accuracy
* Goto and Check Size actions use $J jog commands so the speed can be controlled and they can be safely stopped
* Step calculators for settings $100, $101, $102 and $103 remember their last used settings
* Few minor fixes

v1.0.2
* Improved error handling in the auto-updater
* Fix for search in file dialogs on MacOS

v1.0.0

This is the first release of Groove Control.
It has the features from the original OpenBuilds CONTROL, plus
* Ability to view machine coordinates
* Recent file history
* Recent work origin history
* Toolpath simulation controls
* Macro manager
* Heightmap tool
* Many more improvements and bugfixes
